# Variable and data Type 
## Variable 
variable is memory container to store data 

variable is most important concept in programming .
without variable "
- No calculation 
- No automation 
- No Testing framework 
- No database handling 
- No AI/ML 

## How python store variable internally
step 1 - create object "saraswati" in memory 
step 2 - create variable name 
step 3 - links variable to memory 
- variable does not store actual value 
- first it store address of object in memory 

## rules of declare variable 
- start with underscore or letter 
- don't provide space between variable 
- don't use python keyword like class , public 
- don't declare data type , automatically it detect the data type 
- don't start with number
- don't use special character

## why variable are called "variable"
because of value can change anytime so that is called variable 

## Data type 
Data type defines :
what kind of value variable stores.

example : 
- Name - text
- Age - number 
- salary - decimal 
- status - true/false 
python automatically identifies data type . 

python doesn't have separate char data type 

## why data types are important 
- python cannot know what operation to perform 
- cannot calculate numbers 
- cannot store text properly 
- cannot validate conditions
