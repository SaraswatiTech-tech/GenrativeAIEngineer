# Python Notes

## Introduction to Python

Python is a powerful general-purpose programming language.  
It is used for:
- Software Development
- Game Development
- AI Applications
- Automation
- Data Science

Python is called a high-level language because it is easy for humans to read and write.

Python focuses more on readability and simple syntax compared to other programming languages.

Python is designed to make coding simple and fast.

---

## Why Learn Python?

- Easy to understand because Python uses simple English-like syntax.

Example:

```python
if age > 18:
    print("Eligible")
```

- Python requires fewer lines of code compared to other programming languages.
- Python is portable, so you can run it on Windows, Linux, and macOS.
- Python has huge demand in the industry.

---

## Features of Python

- Python has simple syntax, so it is easy to read and write.
- Python is open source, so you can use it for free.
- Python is an interpreted language, which means Python executes code line by line.
- Python is dynamically typed, which means you do not need to declare variable types explicitly.
